Getting started

Sign up, log in, and onboarding

Actor
A new user
Goal
Go from first visit to a working account and a first useful action

Browse before signing up, onboarding tooltips that ask for a login only when you try something, Google or email sign up with verification, a welcome message, and a getting started guide

Goal

Highlights
Pick your agent (Claude Code, Cline, Codex and more) or a container type, and the copyable command updates in place
